نسخهٔ آماده برای سرور شخصی (Node.js 22)

نصب
  ۱. این پوشه را روی سرور بگذارید.
  ۲. Node.js نسخهٔ ۲۲ یا جدیدتر لازم است.
  ۳. در همین پوشه:
       npm install
       npm run build
       PORT=8080 HOST=0.0.0.0 npm start
  ۴. برنامه روی پورت 8080 بالا می‌آید. جلوی آن nginx یا caddy بگذارید و HTTPS بدهید.

توسعه روی کامپیوتر خودتان
  npm install
  npm run dev
  سپس مرورگر را باز کنید روی پورت 8080.

داده کجا ذخیره می‌شود
  داخل مرورگر هر کاربر (localStorage با کلید rokhsat-desk).
  پایگاه‌دادهٔ مشترک ندارد. اگر چند نفر از چند دستگاه همان فهرست را بخواهند، این بسته آن را ندارد.

فونت‌ها
  با npm install از بستهٔ fontsource می‌آیند (وزیرمتن و لاله‌زار).
  فایل جدا لازم نیست.
